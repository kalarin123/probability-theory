# Лабораторная работа № 4. Условная вероятность и формула полной вероятности

## Что нужно сдать

**Письменно (без Python):** задачи из учебника Н. Ш. Кремера № 1.73, 1.74, 1.75 и 1.79. Пошаговые решения с «Дано», формулами и ответами находятся в [файле письменной работы](Решения_ЛР4.md).

**В Jupyter Notebook:** только задача с двумя урнами: в первой 15 белых и 5 чёрных шаров, во второй 6 белых и 1 чёрный. Из первой переносят 3 шара во вторую, затем извлекают один шар из второй. [Lab4.ipynb](Lab4.ipynb) содержит условие, классическое решение по формуле полной вероятности, проверку другим способом и моделирование методом Монте-Карло (100 000 испытаний).

**Теоретический ответ задачи с урнами:** 33/40 = 0,825 = 82,5 %.

Лабораторная работа № 4 также включена в [общий Jupyter Notebook № 1–4](../theory_probability_labs_1-4.ipynb), причём письменные задачи в него не дублируются.

Для запуска отдельного `Lab4.ipynb` достаточно стандартной библиотеки Python.
