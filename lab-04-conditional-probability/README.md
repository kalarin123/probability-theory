# Лабораторная работа №4. Условная вероятность

В лабораторной работе рассмотрены условная вероятность, формула полной вероятности и формула Байеса.

## Файлы

- [Лабораторная работа №4 — Jupyter Notebook](Lab4.ipynb) — условия, пошаговые математические решения, вычисления и проверки на Python.
- [Письменные решения лабораторной работы №4](Решения_ЛР4.md) — решения с формулами без программного кода.

## Задания

Задачи № 1.73, 1.74, 1.75 и 1.79 из блока лабораторной работы, а также задача о двух урнах: сначала аналитическое решение по формуле полной вероятности, затем моделирование методом Монте-Карло.

Запуск: откройте `Lab4.ipynb` в Jupyter Notebook или JupyterLab и выполните ячейки по порядку. Для лабораторной работы №4 достаточно стандартной библиотеки Python.
